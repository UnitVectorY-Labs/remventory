# remventory

A personal inventory system powered by LLMs to aid in searching and inventorying.


A visual home inventory with Remy, your hamster librarian. Catalog belongings with pictures, overlapping tags, approved shared fields, creation templates, and named reference links. Use the visible Remy composer for natural-language tasks and dynamic results, or browse and search directly. AI changes require your approval.
